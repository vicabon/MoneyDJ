# 股價三源交叉比對 & 走勢圖

純前端靜態網頁（HTML + CSS + JavaScript），可直接放在 GitHub Pages 上使用。

## 部署
1. 把 `index.html`、`style.css`、`app.js` 推到 GitHub repo。
2. Settings → Pages → Source 選 `main` branch / root。
3. 瀏覽 `https://<帳號>.github.io/<repo>/`

可用網址參數分享查詢：`?s=QQQ,QLD,0050&from=2025-01-01&to=2025-12-31`

## 比對方式（只比每日收盤價）
- 各來源收盤價四捨五入到指定小數位（預設 2 位）後比較：
  - **完全相同** → 直接採用。
  - **3 個以上來源不同，但都在平均值 ±1% 以內** → 採用平均值。
  - **超過 ±1%，或只有 2 個來源且不同** → 列為**警示**；3 個以上來源時標出偏離中位數超過 1% 的「疑似錯誤來源」。
  - 有來源缺漏但其餘相同 → 標示「來源缺漏」。
- ±1% 可在「進階設定」調整。
- 不同來源的價格基準不同（原始價 vs 分割調整價），比對前先統一換算為原始價；
  分割事件台股取自 FinMind `TaiwanStockSplitPrice`，美股由原始價與調整價的日變動推算。
- 走勢圖使用分割調整後的「採用收盤價」（未含股息），可切換累積報酬 % / 價格與對數座標；在圖上左右拖曳可放大區段（累積報酬以區段首日重新起算），按「重設縮放」還原。
- **縱軸觀察線**：在走勢圖上單擊（或用日期欄位）加入最多 8 條觀察線 A、B、C…，再點一次可移除。
  下方比較表列出每個標的在各觀察線的收盤價（分割調整後）與自查詢開始日起的累計報酬率、相鄰觀察線之間、第一條到最後一條、以及最後一條到區間末的漲跌幅。
  觀察線會存在網址參數 `m=` 中，可分享。
- 所有 prompts 紀錄於 `PROMPTS.md`。
